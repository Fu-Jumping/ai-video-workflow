# official-ai-video

The default video platform is Seedance 2.0 in all-purpose reference mode. Steps 3-5 use `镜头组-001/` directories, one shot maps to one 15-second generation task, and formal video prompts explicitly require no music and no subtitles.

The flagship workflow pack for AI video creators.

- Includes the default Step 0 to Step 6 workflow; complete-script projects can use script mode and start from Step 1.
- Ships runtime skills, workflow rules, templates, checks, and IDE integrations.
- Powers the default `ai-video-workflow init` path.
