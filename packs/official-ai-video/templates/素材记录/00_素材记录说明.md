# 素材记录说明

这个目录记录"每个素材现在到哪一步了"，让你不用翻文件、不用问人就知道：图生成出来没有、下载下来没有、你自己看过没有、最终选了哪一版。

## 这里的目录各管什么

| 目录 | 放什么 | 谁维护 |
| --- | --- | --- |
| `素材记录/` | 每个素材一份记录，写它的身份、轮次、候选和当前选用 | 工具写，你只看 |
| `素材记录/生成批次/` | 每次提交生成时的提示词、参考图顺序、平台参数和结果 | 工具写，用来复查"当时到底发了什么" |
| `工作记录/` | 日常制作过程记录 | 工具写 |
| `工作记录/修改提案/待确认/` | 需要你点头的改动，先放这里，不直接改正文 | 工具写，你确认后才动 |
| `assets/library/` | 长期留用的素材库 | 你放，工具引用 |
| `outputs/` | 每次生成的产出文件 | 工具写 |

## 一个素材的身份怎么认

身份由三段组成：类别 + 对象编号 + 用途。例如 `角色-001` 的 `造型-01`，和 `角色-001` 的 `特写-01` 是两个不同的素材，各自有各自的记录，不会互相覆盖。

展示名可以随时改（把"角色-001"叫成"阿云"），改名字不会改变身份，也不会丢历史。

## 身份键（工具内部格式）

每份记录顶部的 frontmatter 里有一个「身份键」字段，是工具内部认素材的唯一编号，格式固定为「类别:对象编号/用途」，三段缺一不可：

- 类别只认六个英文小写值：`character`（角色）、`scene`（场景）、`prop`（道具）、`style`（风格）、`keyframe`（关键帧）、`video`（视频）。
- 示例：`video:镜头-001/视频`（镜头-001 的成片视频）；`character:角色-001/造型-01`（角色-001 的 1 号造型）；`keyframe:镜头-015/关键帧-01`（镜头-015 的 1 号关键帧）。
- 反例：`video:镜头-001`——缺「/用途」段，解析不了，校验会报「身份键」无法解析，并在报错里带上原值和期望格式。

身份键由工具写入，不要手改；改了等于换了一个素材。展示名（标题）随便改，不影响身份键。

## 文件名怎么读

`镜头-015_关键帧-01_v002_c03.png`

- `镜头-015` 对象编号
- `关键帧-01` 用途
- `v002` 第几次提交（轮次）
- `c03` 这一轮里的第 3 个候选

轮次只增不减。失败了的那一轮也占着号，不会被后来的轮次顶替；补下载沿用原来的轮次和候选号，不会重新排号。

## 已下载的文件放在哪个目录

按记录身份拼目录，一条记录只有一个位置，不要另放副本：

| 类别 | 目录 | 例子 |
| --- | --- | --- |
| 视频 | `outputs/video/<对象编号>/` | `outputs/video/镜头-001/镜头-001_v001_c01.mp4` |
| 关键帧图片 | `outputs/images/<对象编号>/<用途>/` | `outputs/images/镜头-001/关键帧-01/镜头-001_关键帧-01_v001_c01.png` |
| 其他参考素材 | `outputs/references/<类别>/<对象编号>/<用途>/` | `outputs/references/角色/角色-001/造型-01/…` |

工具的自检、粗剪时长探测都按这个目录找文件；文件放错了位置会报「记录写已下载但文件不存在」，或者粗剪表里时长显示「未知」。

## 「当前选用」填什么

「当前选用」一栏填**所选候选的文件名**，不是填「是」：

- 正确写法：`当前选用：镜头-001_v001_c01.mp4`（必须是上面候选清单里的某个文件名）。
- 错误写法：`当前选用：是`——工具按文件名匹配候选，写「是」匹配不到任何候选，列表里会显示「未选」，看起来像什么都没选过。

## 四个状态是分开的，不要混着看

| 状态 | 意思 |
| --- | --- |
| 平台状态 | 远端生成到哪一步：未生成 / 生成中 / 平台已完成 / 平台失败 / 状态未知 |
| 下载状态 | 文件有没有落到本地：未下载 / 已下载 / 下载失败 / 下载状态未知 |
| 审核状态 | 你看过没有：未审 / 已审可用 / 已审不可用 |
| 选用 | 这一版是不是最终用的：是 / 否 |

生成成功不等于下载成功，下载成功不等于你看过，你看过也不等于你选了它。工具不会替你判断后两项。

## 失败分三种，处理方式不一样

| 失败类型 | 什么情况 | 该怎么做 |
| --- | --- | --- |
| 远端状态未知 | 问平台拿不到确定答复（超时、网络断、答复读不懂） | 先重新查状态，不要直接重发，可能已经生成好了 |
| 远端明确失败 | 平台明确说这次生成失败 | 可以改提示词后重发，新一轮占新号 |
| 生成成功但本地保存失败 | 平台那边已经有结果，只是没存到本地 | 只补下载，不要重新生成，避免白花额度 |

## 不要手改的东西

- 记录顶部的身份信息（类别、对象编号、用途）不要手改，改了等于换了一个素材，历史会断。
- 不要手改轮次号和候选号，也不要手动重命名产出文件，否则记录和文件对不上。
- 要改选用哪一版，改"选用"这一列，不要删别人的行。
