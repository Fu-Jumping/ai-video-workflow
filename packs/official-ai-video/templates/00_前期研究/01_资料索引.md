# 资料索引模板

## 来源 ID 规则

- 来源 ID 使用 `SRC-0001`、`SRC-0002` 递增。
- 关键事实、现实人物、真实场景、时代细节和视觉细节必须能回链到来源 ID。
- 不把无法复查的平台内部参数、账号信息、cookie、token 或私信内容写入本文件。

## 资料索引

| 来源 ID | 来源类型 | 标题 | 作者/机构 | 平台 | 发布日期 | 采集日期 | 链接或相对路径 | 可信度 | 创作用途 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| SRC-0001 | 新闻/采访/历史/视频/评论/网页/本地文件 |  |  |  |  |  |  | 待核验 |  |

## 访问限制

| 来源 ID | 限制类型 | 说明 | 对创作的影响 |
| --- | --- | --- | --- |
| SRC-0001 | 公开/需登录/访问失败/版权限制 |  |  |

## 本地资料库

本地资料库位于 `_资料库/SRC-xxxx/`。默认只把 `metadata.json`、`source-card.md` 和匿名化 `comment-sample.md` 纳入版本库；`raw/`、`media/`、`full-comments/`、`browser-profile/` 和 `cookies/` 不进入版本库。
