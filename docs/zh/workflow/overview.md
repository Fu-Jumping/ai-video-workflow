# 工作流总览

默认研究模式包含八个步骤：

0. 前期研究
1. 策划
2. 设定
3. 分镜
4. 图片提示词
5. 视频提示词
6. 执行方案
7. 发布物料

如果项目已有完整剧本，可用 `--start-from script` 或关闭 `workflow.research_step.enabled`，从 Step 1 到 Step 7 运行。

Step 3 与 Step 4 必须保持帧级对齐。Step 6 是执行方案系统，不只是清单。

## 正文放在哪里

创作正文的唯一事实源是项目的 `内容/` 内容树，按场 / 镜头组 / 镜头 / 分镜四层组织：

- Step 3 写内容树：场总览、镜头组总览、镜头汇总、单分镜文件，以及两份总表
- `03_分镜脚本/` 只放 `00_内容树索引.md`，指向内容树，不复制正文
- Step 4 的图片提示词、Step 5 的视频提示词保留为完整执行文件，由内容树生成，供平台直接复制

内容树里的自动区块和人工区块用 HTML 注释标记区分，刷新只替换自动区块，不覆盖人工区块。

项目配置文件 `project.config.yaml` 有 `content.format_version: 1` 时只读内容树；缺这个键的旧项目仍按旧的 03／04／05 目录口径读取。
