# Step 3：分镜

Step 3 把剧本和设定拆成场 / 镜头组 / 镜头 / 分镜四层，正文写进项目的 `内容/` 内容树：

```text
内容/
  00_镜头总表.md
  01_分镜总表.md
  场-XXX/
    00_场总览.md
    镜头组-XXX/
      00_镜头组总览.md
      镜头-NNN/
        00_镜头-NNN.md
        分镜-NN.md
```

`内容/` 是正文唯一事实源。镜头汇总 `00_镜头-NNN.md` 放整镜完整正文（由各分镜按序拼装）和镜头级公共信息；单分镜文件 `分镜-NN.md` 只维护属于本段的三样东西：本段正文、本段关键帧区块、本段视频提示词片段，不重复整镜内容。

`03_分镜脚本/` 只放一份 `00_内容树索引.md`，指向内容树，不复制正文。`04_图片提示词/` 与 `05_视频提示词/` 保留完整执行文件，由内容树生成，供平台直接复制。

一个镜头对应一次默认 15 秒的视频生成任务，镜头编号项目内全局唯一。镜头内部使用 1-6 个从 1 连续编号的“分镜 N”，默认 1-2 个。每镜默认选择一个最重要的关键帧；必要时可增加，但不得多于本镜分镜数或超过 4 张。关键帧不默认绑定首帧或尾帧，关键帧区块必须写清对应分镜和关键时刻，Step 4 才能据此生成执行文件。

自动区块与人工区块用 HTML 注释标记区分，刷新只替换自动区块，不覆盖人工区块：

```text
<!-- avw:auto:start name=区块名 -->
…工具生成…
<!-- avw:auto:end name=区块名 -->
<!-- avw:manual:start name=区块名 -->
…人工维护…
<!-- avw:manual:end name=区块名 -->
```

自动区块名：镜头总表用 `镜头总表`，分镜总表用 `分镜总表`，场总览用 `场镜头组表`，镜头组总览用 `组镜头表`，镜头汇总用 `分镜速览` / `图片提示词` / `镜头段拼装`；镜头汇总的人工区块是 `视频提示词前段` 与 `视频提示词后段`。

项目配置文件 `project.config.yaml` 有 `content.format_version: 1` 时只读内容树；缺这个键的旧项目仍按旧的 03／04／05 目录口径读取，不报错、不自动改写。
