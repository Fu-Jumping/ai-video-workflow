# Step 1：策划

建立故事、视觉与生产基线。

动笔前先完成决策访谈：把 P0 决策（受众、时长与规格、类型基调、结尾、时间线与视角、视觉风格、生产与平台约束、版权伦理）逐组问用户，答复记入 `01_概念策划/00_决策记录.md`；P0 决策未确认或未获用户委托前，不写故事内核与剧本正文。智能体在 Step 1 的第一个实质性回复应当是访谈问题，而不是先给分析或剧本改写。如果宿主支持（如 Claude Code），智能体会用选择题的方式向你提问；不管以哪种方式问，答复都会记入决策记录。访谈协议见 `packs/official-ai-video/skills-longform/film-planner.md`。

如果项目启用了 Step 0，先读取 `00_前期研究/04_创作简报.md`。现实事实必须保留 `SRC-xxxx` 来源 ID；没有来源 ID 的内容只能作为灵感或创作假设。

按场完整剧情写在 `01_概念策划/剧本.md`；探索想法写在 `工作记录/探索/`，确认后才进入剧本。
