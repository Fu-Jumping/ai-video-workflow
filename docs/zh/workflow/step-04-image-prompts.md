# Step 4：图片提示词

Step 4 生成的是完整执行文件：从项目 `内容/` 内容树里对应分镜文件的关键帧区块生成，供平台直接复制，一份文件对应一个关键帧区块。

每份文件对应一个稳定关键帧，文件名固定为 `镜头-NNN-关键帧-NN.md`。元信息必须记录镜头组、镜头编号、对应分镜和关键时刻，并与来源关键帧区块保持一致。

正式文件固定保留：

- `快速导读`
- `中文完整版本`
- `可复制提示词`

中文完整版本与可复制提示词必须独立重建同一画面，并携带 Step 3 声明的全部 `@角色三视图` / `@场景图`。

默认图片平台为 midjourney 时额外保留 `## 平台执行参数`；为 gpt-image-2 时同样保留 `## 平台执行参数`，须写清平台与 LibTV 模型。

改画面事实先改内容树的关键帧区块，再刷新执行文件；不在执行文件里改正文。`project.config.yaml` 有 `content.format_version: 1` 时按内容树读写，缺这个键的旧项目仍按 `04_图片提示词/` 目录口径工作。
