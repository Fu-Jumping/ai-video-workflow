### D13 桌面应用（apps/desktop）M0 实施决策集合 `[临时决策]` 2026-09-15

2026-09-14 通宵会话按 `desktop-app-plan-2026-09-12.md` 设计定稿实施 M0，过程中产生的保守默认决策详见本地实施计划 `docs/local-only/desktop-implementation-plan-2026-09-14.md` §2 A1~A11；该计划不纳入公开候选跟踪。

- 服务层（`apps/desktop/src/main/services/*`）为纯 Node 模块，不 import electron，路径经参数注入；CLI 子进程执行器用 `process.execPath` + `ELECTRON_RUN_AS_NODE=1`，参数数组传递不经 shell。
- tRPC over IPC 自研最小实现：主进程 `ipcMain.handle` + `router.createCaller` 动态路径调用；渲染层自定义 link；文件变更事件走独立 IPC 通道 `avw:project-event`，不用 tRPC subscription。

- 工程约定：本仓库新代码禁用 `RegExp.prototype.exec` 字面调用（`.exec(` 会被 Mimosa 扫描钩子判定为命令注入并拦截写入），正则提取一律用 `String.prototype.match`。
- 构建设施：`pnpm-workspace.yaml` 的 `allowBuilds` 字段 pnpm 不识别，改为标准 `onlyBuiltDependencies: [electron, esbuild]`；根新增 `.npmrc`（`public-hoist-pattern` 含 electron/vite，electron-vite 需解析到 electron 包）；根 `package.json` 增 `desktop:dev/build/test` 三个脚本，`test` 并入 desktop 测试。
- 版本落点：Electron 44.3.0（无 postinstall，首次 require 时经 `ELECTRON_MIRROR` 懒下载二进制）、electron-vite 5、vite 7、React 18.3、antd 5.29、@trpc 11.18、chokidar 5、zod 4（与 CLI 同版本）。
