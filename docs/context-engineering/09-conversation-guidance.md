# 09 对话引导规范（新手保障板块）

本文件是"对话引导"板块的**口径唯一权威**：定义智能体在与用户对话时的引导行为——首触介绍、初始化护航、每轮状态说明与下一步引导。各载体（根 `AGENTS.md`、根 `CLAUDE.md`、CLI 生成的创作项目 `AGENTS.md`、[05-task-routing.md](./05-task-routing.md) B8）只摘录执行；话术格式以本文为准，禁止各载体自造口径。

## 1. 定位：三层防呆体系中的行为层

| 层 | 形态 | 现状 | 与本板块的关系 |
| --- | --- | --- | --- |
| 机器防呆层 | CLI 守卫、`verify`/`doctor` 门禁、质量检查 | 已建成（防呆专项 Q10-Q15/H1-H8 闭环） | 引导的**落点**：行为层把用户引到门禁前 |
| 文档引导层 | README 新手启动、quickstart 提示词 | 已建成 | 引导的**指向物**：引导只链接过去，不复述 |
| 对话行为层 | 智能体对话规则（本板块） | 2026-08-30 建立 | 把上两层主动送到用户眼前 |

核心分工原则 `[通用规则]`：**行为层把用户引到门禁前，不复述门禁正文**。门禁内容在规范与校验器里只有一份权威；对话引导只说"跑哪条命令、看哪个文件"，避免出现第二份会漂移的规则文本。

## 2. 每轮状态引导 `[通用规则]`

每个**实质性回复**末尾以块引用附两行状态脚注：

> **【当前】** <所处位置与状态>
> **【下一步】** <具体动作>

- **实质性回复**指回答了问题、完成了改动或推进了流程的回复；纯确认（"好的"）、寒暄可省略。用户明确表示不需要引导时，停用。
- 排版原则：**每行只说一件事**，避免长句挤一行不便阅读；固定两行块引用，不加标题、不展开成段落，控制噪音。

**工作位置规则**（先搞清楚"在哪干活"）`[AVW 专用]`：

1. 工具仓库（本仓库）是"车间"：装的是工作流母包（规则、模板、质检标准）+ CLI + 文档站。只有维护这个产品本身时才在这里干活——改规则、改 CLI、改文档。
2. 创作项目是"每道菜的现场"：由 `init` 生成在工具仓库之外的独立目录。初始化之后，Step 0 到 Step 7 的全部对话、全部文件、全部校验都只发生在这个目录里，人和智能体都是。
3. 两条铁律：创作项目里不改工具仓库的东西；工具仓库里不写创作内容。唯一交叉点是一次性的 `init` 命令——在工具仓库里代跑，产物在别处。

初始化交接三步：

1. `init` 生成创作项目（用户只回答名称与位置）。
2. 智能体工作目录切到创作项目、开新会话：新会话的规则由项目内 `AGENTS.md`、`文档/智能体工作区` 与 IDE 运行镜像接管，不再加载工具仓库的 `AGENTS.md`。
3. 此后所有步骤的对话与文件都在项目目录内；CLI 命令外挂——全局安装 `ai-video-workflow`（构建后 `npm install -g apps/cli`）后，在项目内以 `ai-video-workflow verify --project <本项目路径>` 的方式运行。概括为"**规则自足，命令外挂**"。

步骤 → 目录映射（事实源：`apps/cli/src/lib/constants.ts`）：

| 阶段 | 创作项目内工作目录 |
| --- | --- |
| 初始化 | 工具仓库里代跑一次 `init`（唯一交叉点） |
| Step 0 研究 | `00_前期研究/` |
| Step 1 策划 / Step 2 设定 | `01_概念策划/`、`02_世界设定/` |
| Step 3 分镜 | `03_分镜脚本/` |
| Step 4 图片提示词 | `04_图片提示词/` |
| Step 5 视频提示词 | `05_视频提示词/` |
| Step 6 执行计划 | `06_执行计划/` |
| Step 7 发布物料 | `07_发布物料/` |

脚注"当前"的判定即基于上述规则：

- 工具仓库侧（尚未初始化创作项目）：写"工具仓库（未初始化创作项目）"及用户此刻的问题所属阶段。
- 创作项目侧：按上表判断所处步骤，附校验状态（如"已校验通过 / 未校验"）；项目处于非 `standard` 流程模式或已有登记偏离时，附偏离状态（如"· scene-basis 模式"或"· 2 项已登记偏离"），让非标准路线始终可见。

"下一步"的原则 `[通用规则]`：

1. 只指向**真实存在**的命令、文件与门禁（如 `verify --step <N>`、`init`、quickstart 文档），不虚构路径或命令。
2. 不预设用户未表达的意图：给选项而非替用户决定创作方向。
3. 与"必须停止并请求用户确认"的场景冲突时，以停止确认优先，脚注写"等待你确认 <事项>"。

## 3. 首触引导 `[AVW 专用]`

用户首次接触或咨询型输入（"这是什么 / 我能用它干什么 / 从哪开始"）时，回复开头给出：

1. 两三句定位（§2 工作位置规则的白话版）：本仓库是"车间"——工作流母包 + CLI + 文档站，只有维护工作流产品本身时才在这里干活；你要做的每个视频是一个独立的"创作项目"目录，由 CLI `init` 生成在别处，之后 Step 0-7 的全部创作都在那个目录里进行；工具仓库里不写创作内容。
2. 下一步选项：从新手启动开始（让智能体代跑 CLI 初始化）→ `docs/zh/quickstart/beginner-agent-init.md`；或先读 `WORKFLOW_OVERVIEW.md` 了解工作流全貌。

首触引导不重复新手文档正文，只做定位与指路。

## 4. 初始化护航 `[AVW 专用]`

代跑初始化时遵循 `docs/zh/quickstart/beginner-agent-init.md` 的流程：检查依赖与构建 → 逐项询问（项目名、位置、智能体工具、图片/视频平台、起始步）→ 运行 `init` → 报告应打开哪个目录与第一步入口。

初始化完成后的**交接三步**必须在最终回复中讲清（完整口径见 §2 工作位置规则）：项目建在哪个目录 → 用户应把智能体工作目录切到项目目录开新会话（规则由项目内 `AGENTS.md` 与运行镜像接管）→ CLI 命令外挂（全局 `ai-video-workflow`，`--project` 指向本项目）。

挂载点（已存在，勿重复建设）：

- `init` 的 next steps 输出（`apps/cli/src/lib/init.ts`）；
- next steps 内置的"第一句话"模板（让用户复制给新项目的智能体）；
- 生成的创作项目 `AGENTS.md` `## 对话引导` 节（见第 6 节载体表）。

## 5. 使用中防呆引导 `[AVW 专用]`

- **步骤推进前**：提醒先运行对应 `verify --step <N>`，通过后再进入下一步。
- **临近禁改区时**（运行镜像、`_views/`、生成投影等）：提醒那是生成物，源头在别处（口径见 [00-project-context.md](./00-project-context.md) §2）。

### 校验失败与偏离的分类处置 `[AVW 专用]`

校验失败先分类，再决定引导方向：

1. **内容问题**：引导用户阅读错误信息、回到出错的步骤源文件修复，而不是改校验器迁就内容。
2. **合理流程偏离**（如轻量镜头不建关键帧、场景图兼任形象基准、临时跳过某类产物）：引导用 `deviation add` / `set-mode` / `set-shot-mode` **显式登记**后再继续（模式与命令见 `docs/zh/workflow/supported-deviations.md`）。红线：未登记的偏离不得静默绕过；登记必须带 reason，让偏离可见可审。
3. **涉及已完成步骤的改动或平台口径变更**：先停止确认（见根 `AGENTS.md` 确认场景），确认后再登记或修改。
