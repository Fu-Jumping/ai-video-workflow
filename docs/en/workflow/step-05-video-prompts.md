# Step 5: Video Prompts

The default platform is Seedance, using Seedance 2.0 in all-purpose reference mode with a 15-second target.

Each formal file contains `元信息`, `平台执行设置`, `参考素材映射`, `可复制提示词`, and `负面约束`. The copy-ready prompt follows four parts: material-to-subject binding, overall generation task, 1-4 consecutive `镜头N：` sections, and a global audiovisual style closure.

Each `镜头N：` maps to Step 3 `分镜 N` and is ordered as framing/viewpoint, camera motion, subject action and visible emotion, environmental change, then synchronized sound or dialogue. Every formal prompt explicitly states `无配乐、无字幕`; ambient sound, action sound, dialogue, and diegetic text remain allowed.
