# Workflow Overview

The default research workflow has seven steps:

0. Research
1. Concept
2. Setting
3. Storyboard
4. Image Prompts
5. Video Prompts
6. Execution Plan

If the project already has a complete script, use `--start-from script` or disable `workflow.research_step.enabled` and run Step 1 through Step 6.

Step 3 and Step 4 must stay frame-aligned. Step 6 is an execution plan system, not just a checklist.
