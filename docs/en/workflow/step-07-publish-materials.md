# Step 7: Publish Materials

For the finished-video publishing phase, this step turns Step 1 story kernel highlights and Step 3 storyboard highlights into publish-ready text materials for each platform.

Each formal material file always contains `来源亮点`, platform-partitioned `## 平台名` sections, and a trailing `避免:`. The default covered platforms are: 抖音/快手, B站, 小红书, 视频号, and YouTube. Platform specifications (title character limits, description length, hashtag format, emoji, language) are governed by `00_发布总表.md`.

This step only produces materials and does not record post-publication platform status. Public-facing materials must not contain internal project codenames or invent selling points that do not exist in the finished video.
