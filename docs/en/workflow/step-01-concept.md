# Step 1: Concept

Define story, visual, and production baselines.

Before writing, run the decision interview: confirm the P0 decisions with the user group by group (audience, duration and specs, genre and tone, ending, timeline and POV, visual style, production and platform constraints, rights and ethics) and record answers in `01_概念策划/00_决策记录.md`. Do not write the story core or script until the P0 decisions are confirmed or explicitly delegated.

If Step 0 is enabled, read `00_前期研究/04_创作简报.md` first. Real-world facts must keep their `SRC-xxxx` source IDs; uncited material can only be used as inspiration or creative assumptions.
