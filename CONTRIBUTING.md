# Contributing

## Development

1. Run `pnpm install`
2. Run `pnpm --filter ai-video-workflow test`
3. Run `pnpm build`

## Rules

- Write commit subjects and bodies in Simplified Chinese; keep conventional type prefixes (`feat:`, `fix:`, ...), code identifiers, paths, and tracking codes (Q/H/D/F) as-is.
- Keep canonical paths in English.
- Keep public examples non-proprietary.
- Preserve Codex dual runtime layers.
- Keep relative links only.
